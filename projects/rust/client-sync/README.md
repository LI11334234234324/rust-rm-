# Rust 同步客户端

完成内容见[公共同步客户端任务](../../../common/tasks.md#同步客户端)。开发环境、检查命令和启动命令见 [Rust 路线](../README.md)，必须在本目录执行。

## 代码结构

| 路径 | 职责 |
| --- | --- |
| `src/main.rs` | 解析 `--url`、读取交互输入并运行命令循环 |
| `src/lib.rs` | 多行文本处理、请求构造、响应解析和令牌状态更新 |
| `tests/connection.rs` | 连接与请求处理集成测试 |

## 开发说明

从 `lib.rs` 的请求函数和命令分派开始，保持命令行解析集中在 `main.rs`。实现任务时优先扩展命令、请求体构造和令牌保存逻辑，不需要引入异步 HTTP 客户端。

启动后的操作见[共通交互](../../../common/tasks.md#共通交互)。

## 多行文本输入

`echo` 和 `put` 使用相同的输入规则：

- 单独一行的 `.` 结束输入，不计入正文。直接输入 `.` 表示空文本。
- 正文为单独的 `.` 时输入 `..`。要输入以两个点开头的正文行，在行首额外加一个点，例如输入 `...x` 表示正文 `..x`。其他行原样保留，包括 `.env`。
- 多行正文之间保留换行。要保留末尾换行，在结束标记前多输入一个空行。
- 如果正文全部为空行，每个空行表示一个换行。输入结束（EOF）也会结束文本输入。

例如，要输入 `hello\n.\n`，依次输入 `hello`、`..`、一个空行和 `.`：

```text
hello
..

.
```
